# Online Kanban Task Management Website Application

## Overview
The **Online Kanban Task Management Website Application** was proposed and developed as an academic project to support efficient task management for system users.  
This project demonstrates collaboration, system design, and development skills in building a functional web-based solution.

## Stakeholders
- **System Users**

## Project Scope
This project was developed for academic learning purposes, showcasing teamwork and technical skills in full-stack web development.

## Purpose
This project serves as an **academic assignment** to demonstrate system design, development, and collaboration skills in building a functional hostel management solution.

### Key Features
- 🔑 **User Authentication** – Secure login and registration system.  
- 📝 **Task Management** – Create, update, and delete tasks.  
- 🔍 **Sorting & Filtering** – Organize tasks by status, category, or priority.  
- ⚙️ **CRUD Operations** – Full control over task data.  

👉 **Responsibility Highlight**: Developed the **User Authentication** feature.
